# Индексация сайта в поисковых системах

Этот файл объясняет, какие технические файлы отвечают за поисковую индексацию сайта «Мечты добрых сердец», где они лежат и что в них нужно отредактировать перед запуском.

## Где лежат файлы индексации

Все файлы, которые читают поисковые роботы (Яндекс, Google и др.), находятся в каталоге:

```
artifacts/site/public/
```

После сборки сайта они попадают в корень публичного домена и доступны по адресам:

- `https://ваш-домен.ru/robots.txt`
- `https://ваш-домен.ru/sitemap.xml`
- `https://ваш-домен.ru/favicon.ico`

## Список файлов

| Файл                                      | Назначение                                             |
|-------------------------------------------|--------------------------------------------------------|
| `artifacts/site/public/robots.txt`        | Правила обхода для поисковых роботов                   |
| `artifacts/site/public/sitemap.xml`       | Карта сайта со списком страниц                         |
| `artifacts/site/index.html` (тег `<head>`)| Мета-теги: `title`, `description`, Open Graph, Twitter |

## Что нужно поменять перед публикацией

### 1. `robots.txt`

Откройте файл `artifacts/site/public/robots.txt` и замените заглушку домена на ваш реальный домен:

```
User-agent: *
Allow: /
Disallow: /admin
Disallow: /api/

Sitemap: https://ВАШ-ДОМЕН.ru/sitemap.xml
```

### 2. `sitemap.xml`

В файле `artifacts/site/public/sitemap.xml` замените все вхождения `https://example.com` на ваш реальный домен и обновите дату `<lastmod>`:

```xml
<url>
  <loc>https://ВАШ-ДОМЕН.ru/</loc>
  <lastmod>2026-04-21</lastmod>
  <changefreq>weekly</changefreq>
  <priority>1.0</priority>
</url>
```

### 3. Мета-теги в `index.html`

В файле `artifacts/site/index.html` отредактируйте секцию `<head>`:
- `<title>` — заголовок сайта (отображается во вкладке браузера и в выдаче)
- `<meta name="description">` — короткое описание (до 160 символов)
- `og:title`, `og:description`, `og:image`, `og:url` — для красивых ссылок в соц. сетях
- `<link rel="canonical">` — главный адрес сайта

## Регистрация в поисковых системах

После того как сайт опубликован и домен подключён:

1. **Яндекс.Вебмастер** — https://webmaster.yandex.ru
   - Добавьте сайт, подтвердите права на домен (HTML-файл или мета-тег).
   - В разделе «Файлы Sitemap» добавьте: `https://ВАШ-ДОМЕН.ru/sitemap.xml`.
   - В разделе «Переобход страниц» отправьте главную страницу.

2. **Google Search Console** — https://search.google.com/search-console
   - Добавьте ресурс с префиксом URL.
   - Загрузите карту сайта `sitemap.xml`.
   - Запросите индексирование главной страницы.

## Проверка

После выкладки в продакшен убедитесь, что файлы открываются:

```bash
curl https://ВАШ-ДОМЕН.ru/robots.txt
curl https://ВАШ-ДОМЕН.ru/sitemap.xml
```

Оба должны вернуть HTTP 200 и корректное содержимое.
